A simple and responsive Real-Time Character Counter built using HTML, CSS, and JavaScript. This project allows users to type a message while displaying the number of characters entered and the remaining characters in real time.

✨ Features
🔢 Maximum 200 characters
⚡ Real-time character counting
📊 Displays typed and remaining characters
⚠️ Warning message when the character limit is reached
🚫 Prevents typing beyond the maximum limit
📱 Responsive design
🎨 Unique and clean user interface
🛠️ Technologies Used

HTML5 | CSS3 | JavaScript

📚 Project Purpose

This project was created to practice JavaScript functions, DOM manipulation, event listeners, input events, and real-time UI updates as part of my Full Stack Web Development (FSWD) Batch-30 learning journey.

Made with ❤️ while learning Full Stack Web Development. 🚀
